# question-ranking-mcp

A custom **MCP server on Databricks Apps** that ranks questions by quality and relevance,
scoring them with a **Model Serving endpoint that splits traffic 50/50 across two
open-source models**. Everything deploys from a single Declarative Automation Bundle.

Implementation lands in [#1](https://github.com/PSPedro176/question-ranking-mcp/pull/1).
